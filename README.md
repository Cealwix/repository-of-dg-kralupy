# repository-of-dg-kralupy

Jakub Závodský 
Chodím na Dvořákovo gymnázium v Kralupech nad Vltavou do 3. P.
Na informatiku dělám projekt se spolužákem Petrem Marešem. Spolu se snažíme vytvořit si vlastního drona.
Mými koníčky jsou hudba (hraji na klavír), společenské hry (jsem velmi společenský a baví mě vytvářet vlastní deskovky :), kreslení a střelba .
V budoucnu bych chtěl studovat asi architekturu, nebo design počítačových her.
